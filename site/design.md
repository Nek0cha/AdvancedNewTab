# Design — AdvancedNewTab 紹介サイト（site/）

拡張機能本体とは別に管理する、`site/` 配下の紹介サイト専用のロックされたデザインシステム。
ページを追加・改修するときは必ずこのファイルを先に読み、ここに書かれたトークン・声色を使う。
新しいテーマを都度選び直すのではなく、このファイルを直す/拡張する形で育てる。

## Genre

playful（Hallmark genreカタログ）

## 対象読者・目的・トーン

- 対象読者: 「便利そうだから使ってみる」で判断するライト層。技術的な専門知識は前提にしない。
- 主目的: ダウンロード訴求より先に、実際の使用イメージ（ウィジェットを並べたダッシュボード）を
  掴んでもらうことを優先する。
- トーン: playful（親しみやすい・柔らかい）。ふざけすぎない、テック感は残しつつ温かい声。

## マクロ構造ファミリー

ページ種別ごとに1つのマクロ構造を割り当てる。同じファミリー内での構造の使い回しはOK。

- **マーケティングページ（`index.html`）**: Workbench — 製品の「使ってる画面」を主役にし、
  マーケティング文を減らす。ヒーローは実スクリーンショットの代わりに、実際のグリッドウィジェット
  構造を模したCSSアートのミニダッシュボードを使う（偽のブラウザ枠・捏造画像は使わない）。
  ただし「見た目も、細部まで。」セクション（テーマ・背景カスタマイズの説明）に限り、
  `assets/image/dashboard-sample.webp` として実際のダッシュボード画面のスクリーンショットを
  1枚だけ例外的に使用する（`.showcase`、`style.css`参照）。カスタマイズの実例を示すという
  そのセクションの主旨上、CSSアートの抽象化よりも実画面の説得力を優先した判断。ここでも
  偽のブラウザ枠は付けない。README.md（GitHub上、このデザインシステムの対象外）にも
  同じ画像を掲載している。
- **文書ページ（`terms.html` / `privacy.html`）**: Long Document — 手紙・メモのような連続した
  文章として読ませる。カードやバナーで区切らず、見出しは本文に埋め込む。

## テーマ — Hum（カタログテーマ、playfulの既定）

拡張機能本体は常時ダークテーマだが、紹介サイトは意図的に明るいクリーム紙のHumテーマを使う
（訪問者が最初に受け取る印象を「温かく親しみやすい」ものにするための意図的な選択。
ダッシュボード自体の見た目は実際のCSSアート/Web版で確認できる）。

アクセント色は元々ペアイエローだったが、`assets/image/dashboard-sample.webp`（実スクリーンショット、
夜空のような濃い青が支配色）を掲載したことに合わせ、ムーンブルーに変更した。写真から抽出した
主要色（`H≈250〜268`）を踏まえて、既存の`--color-accent-2`（スカイシアン、`H=235`）とは
ある程度hueを離した`H=258`を採用し、CTA/強調用の主アクセントとリンク用のスカイシアンが
混同されないようにしている。

```css
--color-paper:    oklch(97% 0.012 95);   /* クリーム紙 */
--color-paper-2:  oklch(94% 0.016 95);   /* 帯用の少し濃いクリーム */
--color-paper-3:  oklch(91% 0.020 95);   /* ホバー時 */
--color-ink:      oklch(20% 0.012 250);  /* 純黒ではない、寒色寄りの濃色 */
--color-ink-2:    oklch(42% 0.02 250);   /* 本文の少し薄いインク */
--color-accent:   oklch(80% 0.10 258);   /* ムーンブルー — CTA・強調 */
--color-accent-deep: oklch(56% 0.13 258); /* CTAの立体エッジ */
--color-accent-2: oklch(66% 0.18 235);   /* スカイシアン — リンク */
--color-accent-3: oklch(68% 0.24 18);    /* コーラルレッド — ここぞという1点だけ */
--color-rule:     oklch(88% 0.02 95);    /* 罫線 */
--color-focus:    oklch(66% 0.18 235);
```

## タイポグラフィ

- Display: Plus Jakarta Sans 700（角の丸い人文主義サンセリフ）
- Body: Plus Jakarta Sans 400/500
- Mono（コード片のみ）: JetBrains Mono 400
- 日本語は各OS標準のゴシック体にフォールバック（Hiragino Kaku Gothic ProN / Yu Gothic UI /
  Noto Sans JP）— 拡張機能本体のフォントスタック方針と同じ考え方。
- 見出しは常にローマン体（イタリック禁止）。強調は太さかアクセント色で表現する。

## スペーシング

4pt基準スケール。`--space-3xs`(2px) 〜 `--space-4xl`(144px)。セクション間は最低 `--space-3xl`。

## モーション

- イージングは `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` を基本に、CTAボタンのホバーだけ
  Humらしい弾み（`translateY(-2px)` + 立体シャドウの伸び）を許可する。
- カードはホバーで軽く持ち上がる（`translateY(-2px)`、影が広がる）。
- `prefers-reduced-motion: reduce` では、すべてのtransform系アニメーションをopacityのみの
  150ms以内のフェードに縮退する。

## CTA・声のトーン

- プライマリCTA: ムーンブルー地・濃色文字・pill形状・下に一段の立体エッジ（`--radius-pill`）。
- セカンダリCTA: 輪郭線のみ、紙面と同色地。
- コピーは具体的に。誇張・誇大な数値は使わない（実測できない「◯万人が利用」等は書かない）。

## ナビ・フッター（全ページ共通）

- ナビ: N7 Brutal slab相当 — トラッキングを効かせた大文字リンク＋下2pxの罫線。ロゴには
  実際の拡張機能アイコン（`assets/icon/icon-128.png`）を使う。
- フッター: Ft5 Statement相当 — 1行のクロージング文＋リンク列のみのシンプル構成。

## ページ間で共有するもの

- ロゴ・アイコン、アクセント色（ムーンブルー基調）、Display/Bodyフォント、CTAの形。
- ナビ・フッターの構成。

## ページごとに変えてよいもの

- マクロ構造（マーケティング=Workbench / 文書=Long Document）。
- 本文の分量・語り口の密度（文書ページは長め、トップは短く）。
