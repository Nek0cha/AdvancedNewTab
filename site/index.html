オープンソース・Chrome拡張機能

自由度の高い、新しいタブカスタマイズ拡張機能。

時計・検索・よく使うサイト・メモから電卓、世界時計、YouTubeミニプレーヤーまで。 ドラッグで自由に組み替えられる、新しいタブ拡張機能です。

ツールを、好きな場所に。

インストール直後に要求される権限は storage のみ。ブラウザのデータや外部通信が必要な ウィジェットは、実際にそれを置いた瞬間だけ許可を求めます。

時間

デジタル/アナログ時計、最大4都市の世界時計、カレンダー、カウントダウン/アップ、ポモドーロタイマー。

権限不要

検索・リンク

Google / Bing / DuckDuckGo / カスタムURLからその場で検索。よく使うサイトはアイコン付きで登録、プリセットからワンクリックで追加できます。

権限不要

メモ・電卓

ちょっとしたテキストを書き留めるメモ。「1*2+3=」のように文字でもボタンでも計算できる電卓。

権限不要

ブラウザ連携

よく使うサイトの閲覧頻度データ、最近のブックマークを一覧表示。

topSites / bookmarks

外部情報

指定地名の天気（Open-Meteo提供、APIキー不要）、RSS/Atomフィードの新着記事。

対象ホストへの通信

メディア・画像

YouTube / YouTube Musicの再生をシークバー付きで操作。
画像ウィジェットは1枚固定、または複数画像をスライドショー表示。

対象ホストへの通信

細部までカスタマイズ可能。

単色・グラデーション・画像の背景、カードの透明度・角丸・ぼかし、ウィジェット単位の個別スタイルまで調整できます。 レイアウトは3枠まで保存可能です。

インストール方法

Chrome Web Storeには公開していません。(公開予定です。)
GitHub Releasesから配布用のzipを読み込んでください。 Chromium系ブラウザ（Chrome、Edge、Braveなど）であれば動作します。

  1. Releasesページ から最新の advanced-new-tab-0.X.0-chrome.zip をダウンロードし、任意のフォルダに解凍する
  2. ブラウザで拡張機能の管理ページを開く（Chromeならchrome://extensionsにアクセス）
  3. 右上の「デベロッパーモード」をONにする
  4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、解凍したフォルダを選択する
  5. 拡張機能一覧に「AdvancedNewTab」が表示されれば完了

Web版

インストール不要。(一部機能が使えません)
