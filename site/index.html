オープンソース・Chrome拡張機能

新しいタブに、いつもの道具を並べる。

時計・検索・リンク集・メモから電卓、世界時計、YouTubeミニプレーヤーまで。 ドラッグ&ドロップで自由に組み替えられる、新しいタブのダッシュボードです。

ダウンロード インストールせず試す

「ブラウザで試す」は拡張機能なしで動くWeb版です。壁紙やスタートページ代わりにも使えます （データはこの端末のブラウザだけに保存されます。ブラウザ拡張API依存の一部ウィジェットはWeb版では使えません）。

10:24

好きな道具を、好きな場所に。

インストール直後に要求される権限は storage のみ。ブラウザのデータや外部通信が必要な ウィジェットは、実際にそれを置いた瞬間だけ許可を求めます。

時間まわり

デジタル/アナログ時計、最大4都市の世界時計、月表示カレンダー、カウントダウン/アップ、ポモドーロタイマー。

ほぼ権限不要

検索・リンク

Google / Bing / DuckDuckGo / カスタムURLからその場で検索。よく使うサイトはアイコン付きで登録、プリセットからワンクリックで追加できます。

権限不要

メモ・電卓

ちょっとしたテキストを書き留めるメモ。「1*2+3=」のように文字でもボタンでも計算できる電卓（累乗にも対応）。

権限不要

ブラウザ連携

よく使うサイトの閲覧頻度データ、最近のブックマークを一覧表示。

topSites / bookmarks

外部情報

指定地名の天気（Open-Meteo提供、APIキー不要）、RSS/Atomフィードの新着記事。

対象ホストへの通信

メディア・画像

YouTube / YouTube Musicの再生をシークバー付きで操作。1枚固定、または複数画像をフェードでスライドショー表示。

対象ホストへの通信

見た目も、細部まで。

単色・グラデーション・画像の背景、カードの透明度・角丸・ぼかし、ウィジェット単位の個別スタイルまで調整できます。 設定は配置ごとJSONひとつにエクスポート/インポート可能です。

インストール方法

Chrome Web Storeには公開していません。GitHub Releasesから配布用のzipを読み込んでください。 Chromium系ブラウザ（Chrome、Edge、Braveなど）であれば動作します。

  1. Releasesページ から最新の .zip をダウンロードし、任意のフォルダに解凍する
  2. ブラウザで拡張機能の管理ページを開く（Chromeなら chrome://extensions）
  3. 右上の「デベロッパーモード」をONにする
  4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、解凍したフォルダを選択する
  5. 拡張機能一覧に「AdvancedNewTab」が表示されれば完了

まずはブラウザで、触ってみてください。
